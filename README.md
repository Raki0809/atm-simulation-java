# ATM Simulation with PIN Authentication & Input Validation

A console-based Java application simulating core ATM operations 
with secure authentication and robust input handling.

## Features
- PIN-based authentication with account lockout after 3 failed attempts
- Deposit, Withdraw, and Check Balance operations
- Input validation using regex and exception handling
- Prevents crashes from invalid user input

## Tech Stack
Java, Scanner, Exception Handling, Regex

## How to Run
javac Simulation.java
java Simulation
